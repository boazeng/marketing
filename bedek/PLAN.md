## 4. פייסבוק ואינסטגרם — חלוקת עבודה מדויקת

**מה אני לא יכול לעשות:** לפתוח חשבונות ולהזין סיסמאות. זה גבול קשיח אצלי,
ולא משנה איזה MCP מותקן. בנוסף — **אין MCP של מטא מחובר אצלך ואין כזה בקטלוג**
(בדקתי). מה שכן קיים זה Graph API עם המפתחות שלמעלה.

**מה שכן — וזה כמעט הכל:**

| שלב | מי מבצע |
|---|---|
| החלטה על שם משתמש, ביו, תמונת פרופיל, תמונת קאבר, קטגוריה | אני מכין הכל מראש |
| הרשמה ל-Meta Business Suite, יצירת Page, קישור IG | **אתה** — אני יושב לידך ומכתיב מסך-מסך |
| הזנת הפרופיל (ביו/קישורים/פרטי קשר) | **אתה** מדביק את מה שהכנתי |
| הפקת Page Access Token והוספה ל-`.env` | **אתה** לוחץ, אני מסביר איפה |
| **מכאן והלאה — פרסום, תזמון, איסוף מדדים** | **אני**, אוטומטית דרך Graph API |

כלומר: הזנת החשבון היא ישיבה אחת של ~30 דקות, ואחריה אני עצמאי.

⚠️ סדר קריטי: **קודם דומיין, אחר כך חשבונות.** מטא דורשת אימות דומיין
(Domain Verification) כדי לפרסם קישורים בלי הגבלות ולהפעיל פיקסל.
