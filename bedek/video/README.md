# סרטונים

⚠️ **`make_clips.py` עולה כסף אמיתי.** ~0.10$ לקליפ ב-fal.ai, ותקציב החשבון
הוא עשרות דולרים בודדים — לא מאות. הרץ `--plan` בראש, ואל תמחק קליפים
מ-`clips/` בלי סיבה: הם בקאש, ומחיקה מכריחה יצירה מחדש בתשלום.

## הסדר, ולמה הוא זה

```bash
python make_vo.py      # 1. קריינות — אורכה קובע את אורך כל שוט
python make_clips.py   # 2. לייב-אקשן  (⚠️ בתשלום)
python make_cards.py   # 3. כרטיסי טקסט ב-Chromium
python make_music.py   # 4. פאד ב-numpy
python build.py        # 5. הרכבה + גזירות 1:1 ו-9:16
```

**קריינות ראשונה, תמיד.** הסדר ההפוך מייצר מצגת שקריין רודף אחריה.

## שני מנועי קריינות

`make_vo.py`, `make_cards.py` ו-`build.py` מקבלים `--engine`:

| מנוע | מודל | מתי |
|---|---|---|
| `deepdub` (ברירת מחדל) | `dd-etts-3.4` | הטייק הנוכחי — הגייה עברית טובה יותר |
| `elevenlabs` | `eleven_v3` | הטייק הראשון, נשמר להשוואה |

```bash
python make_vo.py --engine elevenlabs    # הטייק הישן, מהקאש
python make_vo.py && python make_cards.py && python build.py
```

כל מנוע כותב ל-`audio/<engine>/` משלו. **זה לא סידור — זו הגנה:**
TTS נגבה לכל יצירה, ותיקייה משותפת הופכת כל החלפת מנוע לתשלום חוזר על טייק
שכבר שילמת עליו, ואת השאלה "איזה קול יותר טוב" לשאלה של מה שבמקרה על הדיסק.

**הקולות ב-Deepdub הם שלנו.** `clone_voice.py` לוקח טייק קיים כדגימה ומייצר
ממנו voice prompt, ולכן הטִמבר של הסרטונים לא השתנה — רק ההגייה. הקטלוג
הציבורי לא היה אופציה: `GET /voice` מחזיר רק קולות שהעלית בעצמך, ו-suffix של
סגנון שממציאים לדובר שלא נושא אותו חוזר 404.

⚠️ **הדגימה היא פלט של ElevenLabs.** להשמיע פלט משלך דרך ספק אחר זו שאלת
רישוי, לא שאלה טכנית — שווה מבט בתנאים לפני שזה יוצא ללקוחות.

⚠️ **כרטיסי הטקסט ב-`clips/` נגזרים לאורך הקריינות שמתחתיהם**, כלומר שייכים
למנוע שהריץ אחרון את `make_cards.py`. החלפת מנוע ב-`build.py` בלי להריץ אותו
מחדש משאירה את שני הכרטיסים לא מסונכרנים. הרינדור חינם; קליפי ה-fal שלידם לא,
ו-`make_cards.py` לא נוגע בהם.

## מה בגיט ומה לא

`scripts.py` ושאר הסקריפטים — כן. `clips/`, `out/`, `audio/`, `cards/` — לא.
מזהי ה-voice prompt של Deepdub **כן** ב-`scripts.py`: הם לא סוד, והם היחידים
שאי אפשר לגלות מחדש מה-API.

⚠️ **חריג שכדאי להכיר:** קליפי fal **אינם דטרמיניסטיים.** הרצה מחדש תיתן
צילומים דומים אבל לא זהים, ותעלה שוב. הקליפים והסרטונים המוגמרים שמורים
ב-SharePoint תחת `TACT/שיווק/בדק/סרטונים/` — משם לוקחים, לא מייצרים מחדש.

## שינוי נוסח

הכל ב-`scripts.py` בלבד — טקסט הקריינות והפרומפטים החזותיים. שנה, ואז
`make_vo.py` → `make_cards.py` → `build.py`. הקליפים לא ייווצרו מחדש.

⚠️ **ביט מיוצר רק אם הקובץ שלו חסר.** להחליף טייק אחד = למחוק את הקובץ ההוא,
לא את התיקייה.

**כלל הניקוד תלוי במנוע.** ElevenLabs צריך ניקוד על כל מילה דו-משמעית;
Deepdub מנקד מחדש בעצמו, ומילה שהכתיב המנוקד שלה חסר נכתבת בכתיב מלא ובלי
ניקוד (`דייר`, לא `דַּיָּר`). ההסבר המלא בראש `scripts.py`.

**קצב ב-`dd-etts-3.4` הוא שקט, לא מהירות.** המודל מתעלם מ-`targetDuration`,
ולכן `PACE` לא נשלח אליו; מה שקובע את הנשימה של הסרטון הוא `TAIL`.
