# OnePage — עמוד אחד ללקוח

```bash
python onepager.py     # -> onepager.html + onepager.pdf + onepager.png
```

| קובץ | מתי |
|---|---|
| `onepager.pdf` | מייל, צירוף להצעת מחיר, הדפסה |
| `onepager.png` | **וואטסאפ** — תמונה נפתחת בצ׳אט, PDF דורש הורדה |
| `onepager.html` | המקור. לא נשלח |

## לפני השליחה הראשונה
מלא את `CONTACT` בראש `onepager.py` — **טלפון** ואופציונלית שם ותפקיד.
כל עוד הטלפון ריק, השורה פשוט נעלמת מהעמוד.

## שני דברים שהסקריפט אוכף
1. **עמוד אחד.** אם התוכן גולש מ-A4, הסקריפט **נכשל עם exit 1** ואומר בכמה
   פיקסלים. OnePage שהופך בשקט לשני עמודים הוא כישלון המוצר הזה.
2. **הצבעים והסימן נקראים מ-`brand/`** — לא מוקלדים. שינוי בפלטה מתגלגל לכאן
   אוטומטית בהרצה הבאה.

## למה זה לא הדפסה של האתר
מי שמקבל את זה קורא אותו בארבעים שניות ומחליט אם לקבוע פגישה. לכן זו **דחיסה
עריכתית** של [`content/messaging.md`](../messaging.md): משפטים קצרים יותר,
פחות טענות, פעולה אחת. המרקדאון נשאר מקור האמת למה מותר לומר.
